# CONTRACT overlay — zistgah/duke2

Thin overlay on the master contract at `zistgah/governance`. It ADDS; it never relaxes.

1. **The plates are canonical.** A defect found later becomes a NEW plate and a new version, never
   an edit to a published one. *Kaivalyik Immutabilis.*
2. **Preserve the primitives.** Act ≠ ACT-R's ACT. Inclination ≠ gradient ≠ probability ≠ intent ≠
   act ≠ execution, and it lives on edges. Zero ≠ absence. Persistence ≠ permanence. Collapsing any
   of these in derived text or metadata is ontological substitution, not simplification.
3. **Preserve the hedging.** Open research questions stay questions; correlation stays correlation.
4. **Decay affects influence, not existence** — and no constitutional object silently decays. Any
   tooling built on this repo inherits that rule.
5. **`assets/figures` is data.** Only declared figures plus the cover may live there; the seeder
   refuses anything undeclared, because an undeclared file WILL be minted.
6. **No vendor name in any text layer** — titles, slugs, config, metadata, overlays.
7. **Nothing pushes or mints without his typed gate.** An AI writes the script; he runs it.
8. **The tool's interface is read, never recalled** — and a discovered verb is not a discovered
   signature (`misty ots stamp <path>`, one path, no globs).
